📱 Hjælp til mobilmenuen

Mobilmenuen kan ikke starte, før browseren tillader JavaScript. Følg guiden til den browser du bruger.

Samsung Internet

1. Tryk på ☰ Menu nederst i Samsung Internet.
2. Tryk Indstillinger.
3. Find Websteder og downloads eller Webstedstilladelser.
4. Find JavaScript og tillad det.
5. Gå tilbage til mobilmenuen og genindlæs siden.

Google Chrome

1. Tryk på ⋮ øverst i Chrome.
2. Tryk Indstillinger.
3. Tryk Webstedsindstillinger.
4. Tryk JavaScript og vælg Tilladt.
5. Gå tilbage til mobilmenuen og genindlæs siden.
